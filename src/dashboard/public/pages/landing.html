What Mochi does

Invite tracking

Check each member's net invite count. Label invite codes by campaign. Leaves and suspicious accounts reduce the total.

Joins are marked as unknown when Mochi cannot identify the invite.

In Discord/invites/leaderboard/invite-label

Server activity

View live member activity, invite use counts, and join and leave trends. Send join and leave logs to a Discord channel.

Moderation

Edit Discord AutoMod rules. Set up a honeypot channel. Apply the same role permissions to multiple channel categories. Enable or disable plugins per server.

Dashboard access

Mochi must be in your server. You need the Manage Server permission to use its dashboard and change settings.
